# VizHop - Full-Stack MERN E-Commerce Platform

VizHop is a modern full-stack e-commerce web application built using the MERN stack (MongoDB, Express, React, Node.js).

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- MongoDB database connection

### Installation
Install dependencies for both frontend and backend:
```bash
npm run install:all
```

### Running the Application

- **Backend Server:**
  ```bash
  npm run start:server
  ```

- **Frontend Client:**
  ```bash
  npm run start:frontend
  ```

## 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
